# Заметки по проверенной батарее: SANYO AL12A32

Что выяснено при работе с адаптером (1 ноября 2026). Всё получено чтением; в батарею ничего не писалось.

## Батарея
- SANYO AL12A32, Li-ion 4S, проектные 2500 мА·ч / 14,8 В, дата выпуска 2012-06-16, серийный 28285 (0x6E7D).
- Контроллер: на плате маркировка `bq 8055 21K G4 A9L8` (TI). Открытого даташита на bq8055 найти не удалось.
- Ячейки заменены на б/у Samsung (около 2000 мА·ч по тестам). Контроллер при этом хранит данные старых ячеек:
  FullChgCap 2367 мА·ч, 80 циклов, RSOC 86 % / ASOC 82 %.
- Статус `0x40C0` = `TCA | INIT | DSG` (TCA — «завершить заряд»). Запрос зарядки: 0 мА / 0 мВ. Банки ~4,18–4,20 В (разброс 17 мВ).

## Что отвечает батарея
- Стандартные SBS-регистры (напряжение, ток, температура, ёмкости, циклы, статус, строки) — читаются, значения совпадают с Be2Works 4.32 DEMO.
- Банки: 0x3C–0x3F (мВ); блок 0x23 содержит те же напряжения. Ещё отвечают нестандартные 0x50–0x5B (назначение неизвестно).
- NACK: запись 0x0001 в ManufacturerAccess (0x00); чтение 0x44 и 0x77–0x7A. То есть схемы доступа к Data Flash bq4050 (0x44) и bq20z (0x77/0x78) не работают.
  Возможные причины: контроллер запечатан или у bq8055 другой механизм. Различить без документации нельзя.
- Be2Works DEMO читает только стандартные регистры; вкладка EEPROM (24C01) для этой батареи не применима, Data Flash в демо не читается.
  Журнал обмена (`cp2112_tool.py log`) это подтвердил: все обращения к адресу 0x0B, две однобайтовые записи (выбор регистра 0x03).

## Что делать с данными после замены ячеек
Пока Data Flash недоступен — обучающий цикл: полный заряд → отдых 1–2 ч → разряд до выключения ноутбука (не ниже ~3,0 В на банку) →
отдых 1–5 ч → полный заряд. Мониторить `tools/battery_gui.py` с записью CSV; дампы регистров до/после сравнивать кнопкой.
Если `FullChgCap` не обновился после двух циклов — нужен инструмент, умеющий писать Data Flash этого чипа.

## Идеи на потом
- Найти документацию bq8055 (TRM) или платный инструмент для ремонта батарей с его поддержкой и записать его обмен через `cp2112_tool.py log`.
- Проверять только чтением; unseal и запись — только после бэкапа и с явным решением владельца батареи.
